# Blue Wave — Surf School

École de surf à Jack Beach, Dar Bouazza.

Cours en groupe : 200 DH pour 2 heures par personne. Cours privé : 300 DH pour 2 heures par personne. Packs négociables.

## Télécharger le site

Utilisez **Code → Download ZIP**, ou téléchargez le fichier `Blue-Wave-GitHub.zip` présent dans ce dépôt.

## Fichiers

- `index.html` : page du site
- `style.css` : styles et adaptation mobile
- `app.js` : formulaires de réservation et interactions
- `images/` : photos et diplômes

Les réservations sont des demandes envoyées via WhatsApp, à confirmer par l’école.
